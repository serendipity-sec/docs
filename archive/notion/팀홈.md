# serendipity 캡스톤

웹어플리케이션보안(캡스톤디자인) · 2026-2학기 · 중부대학교 정보보호학과 · 지도교수 이병천

## 프로젝트

**AI 워크플로 구성요소의 공급망 보안 검사 및 공유 플랫폼**

외부에서 가져온 규칙 파일·스킬·MCP 서버·플러그인을 사용 전에 정적으로 검사하고,
구성요소 사이의 연결과 위험 근거를 그래프로 보여 주며, 검사한 버전과 검토 이력을 팀이 함께 재사용한다.

## 링크

- 문서: https://github.com/serendipity-sec/docs
- 커뮤니케이션: Discord

## 팀 규칙

1. 회의록은 회의 후 **24시간 안에** GitHub `docs/meetings/`에 커밋한다. 커밋 이력이 출석 근거다.
2. 코드 작업은 **GitHub Issues**에만 올린다. 노션에는 링크만 건다.
3. `main` 브랜치에 직접 push하지 않는다. PR + 리뷰어 1명 승인 후 머지한다.
4. 외부 자료를 인용할 때는 **출처 URL과 확인 날짜**를 반드시 남긴다.
5. 외부 코드를 가져오기 **전에** `platform/THIRD_PARTY.md`에 라이선스를 먼저 기록한다.
6. 검사 대상 자료(스킬·MCP 서버·플러그인)는 **실행하지 않는다.** 정적으로만 읽는다.
