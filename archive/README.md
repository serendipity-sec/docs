## 원본 보존

아카이브 자료는 바이트를 유지한 채 경로만 이동했다. 하위 폴더의 상대 배치를 유지하여 자료 사이의 기존 링크를 보존한다.
원본 코드·계획·결과·해시가 서로 연결된 실험 기록은 내용을 수정하지 않았다. `.gitattributes`가 아카이브 전체의 줄바꿈 변환을 방지한다.
[classification-manifest.json](classification-manifest.json)에 이전·현재 경로, 크기, SHA-256을 기록했다.

과거 자료에 나오는 “최종 결과”, “현재 결론”, “프로젝트”는 해당 문서가 작성된 당시의 대상이다. 현재 최종 설계를 대체하지 않는다.
실행 기록의 절대 경로와 명령은 당시 환경의 기록이며, 이번 분류 작업에서 실험을 재실행하거나 명령의 재현 가능성을 새로 검증한 것은 아니다.

## 최종본과 로컬 미리보기

현재 최종 설계의 조사 근거는 `final/research-evidence.md`에 함께 둔다. 최종 문서의 아카이브 참조 링크와 확정 상태 표기만 새 위치에 맞췄다.
열려 있던 로컬 HTML 미리보기를 유지하려고 원래 `proposals/2026-10-03-flowdelta/`는 로컬 호환 사본으로 남겼다. 이 사본은 Git에서 제외하며 GitHub 기준 경로는 `final/` 하나다.
설치 런타임·캐시 등 기존 ignored 자료는 새로 공개하지 않는다.
