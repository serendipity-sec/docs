## 웹 서비스 두 구성

[docs #55](https://capstone2-cxs4239.slack.com/archives/C0C879U084V/p1793590202424299)의 비교 대상은 다음 두 가지다.

1. **FlowDelta 검사 웹 서비스**: 화면 → n8n 요청 접수/작업 조정 → 기존 분석/격리 실행 worker → 독립 판정/결과 조회.
2. **n8n 업무 서비스와 검증 화면**: 화면 → n8n Agent/업무 도구 → 합성 상태 저장소. FlowDelta는 외부에서 전후 버전을 시험하고 독립 관측.

이는 검토 후보이며 기억 관리 서비스 신설·FlowDelta 전체의 n8n 재구현·최종 아키텍처 채택이 아니다. 원문에 [공식 Webhook 문서](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.webhook/) 링크가 있으나 설명 뒤는 잘렸다. 이번 수집은 해당 외부 페이지·n8n 기능·실제 구성/실행을 검증하지 않았다. Slack 출처 확인 11/03과 외부 기능 검증을 구분한다.
