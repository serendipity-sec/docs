# 노션 워크스페이스 구축 가이드

이 폴더의 zip 하나를 노션에 가져오면 팀 워크스페이스가 한 번에 만들어집니다.
담당: 김민우 (도구 관리)

---

## 0단계 — 교육 플랜부터 받으세요 (가장 중요)

**무료 플랜은 멤버가 2명 이상이 되는 순간 워크스페이스 전체에 1,000블록 하드 제한이 걸립니다.**
블록은 문단·불릿·표의 행 하나하나입니다. 4명이 15주 동안 쓰면 학기 중반에 막힙니다.

해결: **교육 플랜(Education Plus)을 받고, 팀원을 "멤버"가 아니라 "게스트"로 초대합니다.**

| | 무료 (멤버 4명) | 교육 플랜 (멤버 1명 + 게스트 3명) |
|---|---|---|
| 블록 | **1,000개 제한** | 무제한 |
| 페이지 기록 | 7일 | 30일 |
| 파일 업로드 | 5MB | 무제한 |
| 게스트 | 10명 | 100명 |
| 비용 | 0원 | 0원 |

신청:

1. **중부대 메일**로 노션 가입 (개인 Gmail 불가 — 학교 발급 메일이 계정 주 이메일이어야 함)
2. 설정(Settings) → 요금제(Billing) → 아래로 스크롤 → **"무료 교육 플랜 받기"**
3. 중부대가 WHED(세계고등교육DB)에 있으면 즉시 승인됩니다
4. 매년 재인증이 필요하고, 졸업해서 학교 메일이 죽으면 플랜도 내려갑니다

> 교육 플랜은 "1인 워크스페이스 + 게스트 100명" 구조입니다. 게스트도 페이지별로 편집 권한을
> 받을 수 있어서 팀 협업에 지장이 없습니다.

---

## 1단계 — zip 하나로 통째로 가져오기

CSV를 하나씩 넣을 필요 없습니다. **페이지 구조까지 한 번에** 만들어집니다.

파일: `docs/notion/serendipity-notion-import.zip`
로컬 경로: `C:\capstone2\docs\notion\serendipity-notion-import.zip`

1. 노션 왼쪽 사이드바 맨 아래 **가져오기(Import)**
2. **Markdown & CSV** 선택
3. 위 zip 파일 선택

이러면 `serendipity 캡스톤` 페이지가 만들어지고 그 안에 데이터베이스 5개가 들어갑니다.

| 하위 페이지 | 내용 |
|---|---|
| 제출물 | 과목 제출물 10건. 마감일·배점·담당·GitHub 경로 |
| 주차 계획 | 15주 강의계획. 1~2주 완료, 3주 진행 중 |
| 회의록 | 회차별 기록 (1회차 포함) |
| 액션 아이템 | 누가 언제까지. **매 회의마다 점검** |
| 조사 자료 | 출처 URL·확인일·해석의 한계 |

> ⚠️ CSV를 엑셀로 먼저 열지 마세요. 한글이 깨진 채로 저장됩니다. zip 그대로 올리세요.

## 2단계 — 가져온 뒤 손볼 것

CSV로 만들면 모든 열이 "텍스트"가 됩니다. 아래만 바꾸면 훨씬 쓸 만해집니다.

| 데이터베이스 | 열 | 바꿀 타입 |
|---|---|---|
| 전체 | `상태` | **선택(Select)** — 시작 전 / 진행 중 / 검토 중 / 완료 |
| 전체 | `담당`, `조사자` | **사람(Person)** — 게스트도 지정 가능 |
| 제출물·주차계획·액션아이템 | `마감일`, `시작일`, `기한` | **날짜(Date)** |
| 액션 아이템 | `우선순위` | **선택** — P0 / P1 / P2 |
| 조사 자료 | `분류` | **선택** — 성장 지표 / 보안 사례 / 표준 / 기존 도구 / 프레임워크 |
| 조사 자료 | `출처 URL` | **URL** |

보기(View) 추가 권장:

- **제출물** → 캘린더 보기 (마감일 기준). 이번 달에 뭐가 터지는지 한눈에 보입니다
- **액션 아이템** → 보드 보기 (상태별) + 필터 `상태 ≠ 완료`
- **주차 계획** → 필터 `상태 = 진행 중` 으로 "이번 주" 보기

## 노션과 GitHub, 뭘 어디에 쓸 것인가

둘 다 쓰면서 경계를 안 정하면 정보가 흩어져서 아무도 안 봅니다.

**원칙: 사람이 논의하는 것은 노션, 코드에 관한 것은 GitHub.**

| | 노션 | GitHub |
|---|---|---|
| 회의록 작성·논의 | ✅ | 확정본만 `docs/meetings/` |
| 제출물 일정·진행률 | ✅ | ✗ |
| 액션 아이템 | ✅ | ✗ |
| 조사 자료·링크 스크랩 | ✅ | ✗ |
| 보고서·설계 문서 초안 | ✅ | 제출본만 `docs/deliverables/` |
| 코드 작업 관리 | ✗ | ✅ Issues + PR |
| 버그·기능 요청 | ✗ | ✅ Issues |
| 코드 리뷰 | ✗ | ✅ PR |
| 커밋·리뷰 이력 | ✗ | ✅ (출석·기여도 근거) |

코드 작업을 노션 칸반에 또 올리면 GitHub Issues와 이중 관리가 되고, 반드시 한쪽이 죽습니다.
**코드 작업은 GitHub Issues에만 올리고, 노션에서는 링크만 겁니다.**

## 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| "블록 한도에 도달했습니다" | 무료 플랜 + 멤버 2명 이상 | 0단계 — 교육 플랜 + 게스트 초대 |
| 교육 플랜 버튼이 안 보임 | 계정 주 이메일이 학교 메일이 아님 | 설정에서 주 이메일을 중부대 메일로 변경 |
| CSV 한글이 깨짐 | 엑셀로 열었다 저장함 | 원본 CSV를 노션에 바로 업로드 |
| 날짜 정렬이 이상함 | 열 타입이 텍스트 | 2단계 — 날짜 타입으로 변경 |
| 노션 내용이 GitHub에 없음 | 정상 | 제출본만 GitHub에 커밋하면 됩니다 |
