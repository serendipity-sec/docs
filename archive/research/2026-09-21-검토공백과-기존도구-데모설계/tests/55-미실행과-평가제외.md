# 미실행·평가 제외 범위

작성일: 2026-09-22. 미실행을 실패나 미탐지로 바꾸어 보고하지 않는다.

## 실행하지 않은 검사

| 대상 | 상태 | 사유와 해석 |
|---|---|---|
| Snyk Agent Scan 0.6.3 snapshot / 후속 조사 0.6.4 | NOT_RUN | 서비스 분석에 필요한 인증 조건이 없어 보안 분석을 실행하지 않았다. 두 버전의 탐지력 비교를 하지 않았다. |
| Cisco·SkillSpector 등의 외부 LLM 의미 분석 모드 | NOT_RUN | 인증이 필요한 모드는 실행하지 않았다. 정적 결과를 이 모드의 결과로 확대하지 않는다. |
| 실제 사용자의 승인 정확도·검토 시간·과신 | NOT_RUN | 사람을 모집한 비교 실험을 진행하지 않았다. 기술적 위험 재현과 구분한다. |
| 공개 악성 유통 원본 실행 | NOT_RUN | 공개 메커니즘을 참고한 자체 축소 fixture만 실행했다. 원본 악성코드의 탐지율이 아니다. |
| Windows/Linux 커널 sandbox 탈출·완전한 MCP 적합성 | NOT_RUN | 실험 host의 제한된 도구·loopback 계약을 평가했다. OS 수준 격리 인증이 아니다. |

원래 A·B·C 12개 설계 명세 전체를 그대로 구현한 것은 아니다. 실행한 Skill·MCP 9개 사례와 별도 통제·논문 기반 확장에 각각 고유 문서를 부여했다.

## 제외 실행을 보존하는 이유

초기 harness에는 정상 add의 optional note가 비민감 loopback 전송을 만드는 문제가 있었다. 이 동작을 공격 성공으로 귀속하지 않고 원본을 보존했다. 초기 저장 122회 중 평가 선택은 54회, 후속 통제 51회, 개발 제외 17회다. 그중 구형 smoke/pilot 10회는 현행 초기 효과 체인 검증기의 범위 밖이다.

논문 기반 `paper-v1-qwen4b`는 정상 흐름 4회와 result.json이 없는 T01 부분 실행 1건을 보존한다. 부분 실행은 fetch와 private 읽기까지 도달했으나 완료·전송 결과가 없어 최종 분모에서 제외한다. `mcp-attacks-v1-qwen4b`의 16회도 정상 업무 문자열 판정 보정 전 smoke로 제외한다. 본 실행은 paper-v2 33회와 mcp-attacks-v2 48회이며, 후자 3회는 STEP_LIMIT이다.

## 아직 검증하지 않은 후속 가설

적응형 공격, 다중 서버 권한 전이, 실제 메모리 오염, 공격 조합, 이름 충돌, Skill 런타임 자기수정·복사 실행, 모델·seed 확대, 독립 사용자 연구는 이번 테스트의 완료 항목으로 세지 않는다. 논문에서 제안하거나 다른 연구가 보고한 성능을 우리 실행값으로 복사하지 않는다.
