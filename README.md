# serendipity · docs

웹어플리케이션보안(캡스톤디자인) 2026-2학기 팀 **serendipity** 의 문서 저장소입니다.
회의록·제출물·조사 자료를 보관하며, 구현 코드는 [`platform`](../../platform) 저장소에 있습니다.

## 프로젝트

**AI 워크플로 구성요소의 공급망 보안 검사 및 공유 플랫폼**
외부에서 가져온 규칙 파일·스킬·MCP 서버·플러그인을 사용 전에 정적 검사하고,
구성요소 사이의 연결과 위험 근거를 그래프로 보여 주며, 검사한 버전과 검토 이력을 함께 공유한다.

| | |
|---|---|
| 팀장 | 박용준 — 전체 일정 관리, 회의 진행, 의사결정 총괄 |
| 팀원 | 김민우 — 도구 관리 |
| 팀원 | 양유상 — 중간/최종 발표 자료 준비 및 발표 |
| 팀원 | 장준서 — 서기, 회의록 작성, 자료 정리 |

고정 회의: **매주 목요일 14시(오프라인) / 토요일 20시(온라인, Discord)**

## 규칙

- 회의록은 회의 후 **24시간 안에** 커밋합니다. 커밋 이력이 출석·참여 근거로 쓰입니다.

- 외부 자료를 인용할 때는 **출처 URL과 확인 날짜**를 반드시 남깁니다.
- 한글(hwpx/docx) 원본과 함께, 리뷰가 필요한 문서는 Markdown 사본을 같이 둡니다.
