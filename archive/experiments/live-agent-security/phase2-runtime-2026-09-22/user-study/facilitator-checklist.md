# 사용자 연구 진행자 체크리스트

상태: **NOT_RUN / 실행 전 템플릿**

이 체크리스트는 연구자가 실제 사람 세션을 일관되게 운영하기 위한 것이다. 현재 완료 표시가 없으며 실제 세션 기록이 아니다. 세션별 체크리스트에는 이름·이메일 대신 무작위 participant ID만 사용한다.

## 연구 개시 전

- [ ] 기관의 연구·윤리 검토 필요 여부와 승인·면제 상태를 문서화했다.
- [ ] 연구 책임자, 연락처, 모집 기준, 보상, 보관 기간, 철회 절차를 확정했다.
- [ ] 표본 수 근거, 주 결과, confidence 과신 기준, timeout, 제외 규칙을 첫 응답 전에 사전 등록했다.
- [ ] reference decision을 두 검토자가 독립 작성했고 불일치 처리 기록을 보존했다.
- [ ] reference table과 case snapshot hash를 동결했다.
- [ ] B0·B1의 source evidence가 동일하며 조건별 추가 finding·정답 누출이 없음을 확인했다.
- [ ] 원본 계보가 같은 사례가 한 참가자의 두 조건에 반복되지 않도록 assignment를 검증했다.
- [ ] 연습 사례가 본 사례와 분리되어 있고 본 분석에서 제외되도록 표시했다.
- [ ] human run manifest를 template에서 복사해 별도 run ID로 만들었다.
- [ ] 합성 `study-trials.jsonl`이 human run 입력이나 결과 경로에 포함되지 않음을 확인했다.
- [ ] 실제 개인 응답을 Git에 저장하지 않는 저장·백업 경로를 확인했다.

## 세션 시작 전

- [ ] 모집 연락처 목록과 연구 응답 저장 위치가 분리되어 있다.
- [ ] 무작위 participant ID와 sequence 배정만 준비했다.
- [ ] 참가자 안내문과 최신 동의서 버전을 준비했다.
- [ ] 화면에 실제 조직·사용자 계정·저장소·비밀정보가 열려 있지 않다.
- [ ] 연구 앱이 올바른 case·조건·presentation hash를 표시하는지 preflight했다.
- [ ] 시간 기록과 evidence event 기록이 작동하되 전체 화면·키 입력·다른 탭을 수집하지 않음을 확인했다.
- [ ] 네트워크·브라우저·확대·접근성 설정과 중단 복구 절차를 확인했다.

## 동의와 안내

- [ ] 참가자에게 참여가 자발적이며 거절·중단에 불이익이 없다고 설명했다.
- [ ] 목적, 절차, 예상 시간, 보상, 위험, 정보 처리, 철회 방법을 설명했다.
- [ ] 실제 비밀·개인·조직 자료를 입력하지 말라고 안내했다.
- [ ] 질문을 받고 답변했다.
- [ ] 유효한 동의를 확인하기 전에는 본 과업이나 응답 기록을 시작하지 않았다.
- [ ] 동의 기록은 응답과 분리된 위치에 저장했다.

## 연습 과업

- [ ] ALLOW·HOLD·DENY의 의미를 동일한 문구로 설명했다.
- [ ] confidence가 자신의 판단에 대한 확신임을 설명했다.
- [ ] HOLD를 실패나 악성 판정으로 설명하지 않았다.
- [ ] 조건과 무관한 연습 사례를 사용했다.
- [ ] 연습 결과가 본 데이터에 포함되지 않음을 확인했다.

## 본 과업 진행

- [ ] 참가자가 승인·보류·거절 중 하나를 스스로 선택하게 했다.
- [ ] 정답, 위험 단어, 특정 evidence 또는 더 안전해 보이는 선택을 암시하지 않았다.
- [ ] 참가자의 질문이 절차 문의인지 내용 판단 요청인지 구분했다.
- [ ] 절차 문의에는 정해진 스크립트로 답하고 판단 요청에는 정답을 제공하지 않았다.
- [ ] break, timeout, 페이지 오류, 재접속, facilitator 개입을 즉시 기록했다.
- [ ] 잘못 표시된 사례를 임의로 교체하지 않고 technical failure로 표시했다.
- [ ] 참가자가 중단 의사를 밝히면 즉시 과업을 중단하고 철회 절차를 안내했다.

## 세션 종료

- [ ] 제출된 trial 수와 timeout·중도탈락·기술 실패 상태를 확인했다.
- [ ] 참가자에게 선택적 사용성 질문과 자유 의견을 요청했다.
- [ ] 자유 의견에 개인·조직 정보가 포함됐는지 검토하고 비식별화 절차로 보냈다.
- [ ] 보상 절차가 응답 데이터와 분리됐는지 확인했다.
- [ ] participant ID 외의 식별 정보가 trial·event 로그에 없는지 확인했다.
- [ ] 철회·문의 연락처를 다시 제공했다.

## 일일 종료

- [ ] allocation ledger, trial log, event log, exclusions가 예상 manifest와 연결된다.
- [ ] source evidence와 presentation hash가 동결본과 일치한다.
- [ ] 누락·중복 trial을 수정하거나 덮어쓰지 않고 원본 상태와 보정 기록을 함께 보존했다.
- [ ] 조건별 완료·중단 현황은 운영 확인에만 사용하고 중간 효과 분석으로 모집을 임의 중단하지 않았다.
- [ ] 접근 제한 저장소에 암호화·백업됐는지 확인했다.
- [ ] 개인 응답 또는 동의서가 Git 작업트리에 생기지 않았음을 확인했다.
