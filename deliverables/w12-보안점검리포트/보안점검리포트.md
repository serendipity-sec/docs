## 2. 점검 방법

- **실제 공격:** 합성 주문 서비스를 uvicorn으로 실제로 띄우고 인증·권한·입력 검증을 공격하는 요청을 보냈다. 사례 입력은 조작한 묶음 파일을 실제 CLI(`flowdelta snapshot`)에 넣었다.
- **자동 검사:** trufflehog 3.99.8(전체 git 이력), pip-audit 2.9.0(잠긴 의존성 전체), Semgrep 1.181.0(`p/python`, `p/security-audit`).
- 결과는 막힘·뚫림을 그대로 적고, 뚫린 것은 고친 뒤 같은 요청으로 다시 점검했다.

## 3. 발견 사항과 조치

### F-01 합성 주문 서비스의 OpenAPI 스키마 무인증 노출 — 낮음, 조치 완료
- **내용:** `flowdelta.baseline.fixture`는 `/docs`·`/redoc`을 꺼 두었지만 `/openapi.json`이 인증 없이 200을 돌려줘, 모든 경로와 매개변수 형식이 보였다.
- **영향:** 서비스는 격리된 Docker 네트워크 안의 합성 서비스이고, 드러나는 정보는 경로 이름뿐이다. 다만 실제 웹 서버(#93)도 FastAPI 기본값을 쓰면 같은 노출이 생긴다.
- **조치:** `FastAPI(..., openapi_url=None)`과 회귀 시험 추가 (platform #111).
- **재점검:** 같은 요청 20개 모두 막힘, `/openapi.json` 404.
- **권고:** 웹 서버에도 `openapi_url=None` 또는 관리자 전용으로 둔다.

### F-02 docs 이력의 연습용 JWT 18건 — 정보
- **내용:** trufflehog가 docs 이력에서 JWT 18건을 찾았다(검증 안 됨). platform은 0건이다.
- **확인:** 모두 9월 사전 조사 때 로컬 OWASP Juice Shop 컨테이너가 발급한 토큰이다. 계정은 앱 기본 관리자(`admin@juice-sh.op`)와 팀 테스트 계정(`@example.invalid`)뿐이다. 실제 서비스에 쓸 수 있는 자격 증명은 없다.
- **조치 권고:** docs 저장소를 학기 말에 공개하기 전에, 팀원 연락처 정리와 함께 이 증거 파일의 토큰을 가린다.

### F-03 비밀 검사 자동화 공백 — 운영
- **내용:** Actions 사용량 초과로 10/22부터 11/12까지 두 저장소의 `secret-scan`을 포함한 워크플로가 꺼져 있었다.
- **조치:** PR당 사용량을 줄인 뒤(platform #98) 11/12에 다시 켰다. 꺼져 있던 기간은 전체 이력 수동 점검(F-02)으로 보완했다.
