### 2-2. "발견→이해→수정→재검증 흐름이 없다" — 폐기

코덱스 A가 ZAP 2.17.0·Semgrep CE 1.177.0·Ship Safe 10.0.0을 OWASP Juice Shop v20.2.0에
직접 실행한 결과, **셋 다 설명과 수정 방향을 준다.** 이 문장으로는 차별화 불가.

**대신 실행에서 드러난 빈 칸 2개:**

| 빈 칸 | 근거 |
|---|---|
| ① 사용자 관계 기반 소유권 검증 | 세 도구 모두 `routes/basket.ts`(A가 B의 장바구니 읽기)를 **0건** 지적. 스캐너는 A와 B가 다른 사람인지 모른다 |
| ② 맥락 맞는 수정 + 대조 검증 | Ship Safe가 **비밀번호** 해시 MD5에 "SHA-256으로 바꾸라"는 맥락상 틀린 수정 제시. 초보가 따르면 고쳤다고 착각 |

단서: Burp **Autorize는 권한별 재요청을 공식 제공**하므로 ①을 "빈 시장"이라 부를 수 없다.
Autorize·Shannon 모두 **미실행** 상태다.

### 2-3. SkilLock 실재 — 기존 주제 차별화 추가 약화

`skills-lock/skil-lock`(★6, Apache-2.0, Go)이 SKILL.md의 capability를 lockfile에 고정하고

## 3. 현재 컨셉 (v2)

> **논지: AI는 당신 머릿속의 규칙을 모른다.**

근거: Deng 외(arXiv 2606.23130 v4) 취약점 1,186건의 실패 모드 중
**Hidden security rules 658건(55%)** 이 1위. 사용자가 말하지 않은 암묵적 규칙을 AI가 몰랐다.
Broken Access Control이 취약 유형 1위(28.58%, 앱의 64%)인 것도 같은 뿌리.

**제품의 일**: 사용자 머릿속 규칙을 글로 꺼내고(규칙 선언 화면) → 실제 요청으로 확인 →
어긋나면 **수정 프롬프트 · 패치 · 프로젝트 규칙 파일(CLAUDE.md/AGENTS.md 조각)** 3종으로 AI에게 다시 가르친다.

화면 6개: 등록 → **규칙 선언** → 검사 → 결과(이야기형) → 수정 → 재검증·준비도

## 5. 지도교수 저장소를 검사 대상 후보로 (신규)

**`github.com/lbcsultan/hunminword`** — 이병천 교수 저장소.

| 항목 | 값 |
|---|---|
| 생성·최근 push | 2026-08-25 (동일일) |
| 언어 | TypeScript · Next.js (create-next-app) |
| 크기 | 2,717KB |
| ★ | 0 |
| **라이선스** | **없음** ← 취급 주의 |
| 특이점 | **`AGENTS.md`(678B)와 `CLAUDE.md`(11B)가 있다** — AI 코딩 도구로 작업한 흔적. `direction.txt`도 존재 |

**왜 의미 있나**

1. **지도교수 본인의 코드**다. 상담에서 "교수님 저장소로 시험해봤습니다"는 설득력이 다르다.
2. **AGENTS.md·CLAUDE.md가 실제로 있다** — 우리가 조사한 그 지침 파일 표준이 교수님 코드에 쓰이고 있다.
   컨셉 v2의 "규칙 파일로 AI를 가르친다"가 가상의 이야기가 아님을 보여준다.
3. Next.js라 **우리 지원 범위 결정에 영향**을 준다. C 실험은 FastAPI였다.

**반드시 지킬 것**

- **라이선스가 없다** = 기본적으로 모든 권리 보유. 코드를 우리 저장소에 **복사·재배포하지 않는다.**
  로컬에서 읽기만 하고, 결과 보고서에는 **파일·행 번호와 짧은 인용**만 남긴다.
- **배포된 서비스가 있더라도 스캔하지 않는다.** 로컬 실행만.
- 결과는 **교수님께 먼저 보고**한다(Responsible Disclosure — 강의자료 수강규칙에 명시된 원칙).
  공개 저장소에 취약점 상세를 올리기 전에 반드시 상의.
- 우리 저장소에는 **보고서만** 올린다. 취약 코드 스니펫은 최소한으로.

→ 검사 지시는 [코덱스-지시-hunminword.md](코덱스-지시-hunminword.md)
