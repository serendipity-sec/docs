# 후보 1 검토 기록 — 2026-09-20

이번 기록은 후보 1을 확정한 결정문이 아니다. 다른 후보를 유지하면서, 바이브코딩 보안 주제의 가치·기존 도구와의 차이·웹 보안 과목 산출물 가능성을 검증했다.

1. [기존 도구 직접 비교](01-기존도구-직접비교.md): ZAP baseline/인증 스캔, Semgrep, Ship Safe 실행. Shannon은 CLI 설치 후 제공자 설정 단계까지, Burp/Autorize는 미실행.
2. [논문 정독·데이터셋 확보](02-논문정독-데이터셋.md): 논문 버전과 수치 분모를 확인하고 공개 자료 2종을 다운로드. 자연 발생 바이브코딩 웹앱 데이터셋과 코드 과제 벤치마크를 구분.
3. [실제 생성 앱·감사·패치·재검증](../../../platform/experiments/vibe-app-baseline/README.md): 생성 프롬프트/응답 원본, 기능수리와 보안수리 분리, 공격 차단·정상 기능 대조 23개 통과.
4. [hunminword 규칙·관계 검사](03-hunminword-검사.md): 실제 Next.js 프로젝트에서 지침에 없는 접근 규칙을 선언하고 로컬 HTTP로 검증. Semgrep 0건과 무인증 쓰기 동작을 대조.

현재 판단은 **조건부 발전 가치 있음**이다. “스캐너를 모아서 쉬운 말로 설명”하는 구성만으로는 차별화 근거가 약하다. 회원 A가 B의 예약을 보거나 취소할 수 있는지 보여주고, 수정 후 침범은 막히면서 본인 기능은 유지되는지 검증하는 산출물은 과목과 직접 연결된다.

다음 판단 기준은 경쟁 제품에 기능이 없느냐는 추측보다 **초보가 더 정확하고 빠르게 수정과 검증을 끝내느냐**다. 이번에는 초보 참가자 비교 실험과 경쟁 도구의 실제 패치 적용 비교까지 완료한 것은 아니다. 상세 근거와 한계는 각 보고서에 있다.
