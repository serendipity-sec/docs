## MCP 상태

현재 연결된 Notion MCP로 루트 조회 시 `404 object_not_found`가 반환됐다. 브라우저 접근은 성공했다. 이 팀 워크스페이스의 MCP 관리 화면은 연결 0개였으며, ChatGPT의 다른 계정 연결 버튼에서 추가 인증 화면이 열리지 않았다. 기존 연결을 제거하거나 워크스페이스 공개 범위를 넓히지 않았다. 현재 예약의 실제 수집 경로는 브라우저 내보내기다.

이 문서는 최초 수집에 대한 기록이다. 최신 내보내기의 개수와 해시는 `manifest.json`, 반복 실행 상태는 Git 제외 경로 `.runtime/notion-sync/last-run.json`에서 확인한다.
