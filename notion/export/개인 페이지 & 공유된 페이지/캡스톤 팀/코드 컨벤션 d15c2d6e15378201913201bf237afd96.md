## 📖 코드 컨벤션이란

누가 썼든 한 사람이 쓴 것처럼 보이게 하는 약속입니다. 말로 정한 규칙은 지켜지지 않기 쉽기 때문에, **포매터·린터로 자동화**하는 것이 핵심입니다. 사람은 도구가 잡지 못하는 이름 짓기·구조에만 신경 쓰면 됩니다.

## 🏷️ 이름 규칙 (Python)

| 대상 | 규칙 | 예시 |
| --- | --- | --- |
| 변수·함수·메서드 | snake_case | `alert_count`, `classify_alert()` |
| 클래스 | PascalCase | `TriageAgent` |
| 상수 | UPPER_SNAKE_CASE | `CONFIDENCE_THRESHOLD` |
| 모듈·파일 | 짧은 snake_case | `triage_agent.py` |
| 내부용 | 앞에 `_` | `_parse_raw_event()` |
| 불리언 | `is_`, `has_`로 시작 | `is_false_positive` |
- JavaScript / TypeScript를 함께 쓸 경우
    
    변수·함수는 camelCase, 클래스·컴포넌트는 PascalCase, 상수는 UPPER_SNAKE_CASE를 씁니다. 도구는 ESLint(린트) + Prettier(포맷) 조합이 일반적이고, 스타일 기준은 Airbnb 또는 Standard 가이드를 많이 따릅니다.

## ⚙️ pre-commit으로 자동화

프로젝트 루트에 `.pre-commit-config.yaml`을 두면 커밋할 때마다 포맷·린트가 자동으로 실행됩니다.

```yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: vX.Y.Z  # 최신 릴리스 버전으로 교체
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: vX.Y.Z  # 최신 릴리스 버전으로 교체
    hooks:
      - id: detect-private-key
      - id: check-added-large-files
```

```bash
pip install pre-commit
pre-commit install          # 최초 1회, 이후 커밋 시 자동 실행
pre-commit run --all-files  # 전체 파일 한 번에 검사
```
