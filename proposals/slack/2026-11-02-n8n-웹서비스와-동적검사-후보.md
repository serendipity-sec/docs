## 웹 서비스 두 구성

[docs #55](https://capstone2-cxs4239.slack.com/archives/C0C879U084V/p1793590202424299)의 비교 대상은 다음 두 가지다.

1. **FlowDelta 검사 웹 서비스**: 화면 → n8n 요청 접수/작업 조정 → 기존 분석/격리 실행 worker → 독립 판정/결과 조회.
2. **n8n 업무 서비스와 검증 화면**: 화면 → n8n Agent/업무 도구 → 합성 상태 저장소. FlowDelta는 외부에서 전후 버전을 시험하고 독립 관측.
