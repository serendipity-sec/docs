# 사용자 승인 판단 연구 참여 동의서 템플릿

문서 상태: **NOT_RUN / 서명되지 않은 템플릿**  
동의서 버전: `[모집 전 입력]`  
연구 제목: `[모집 전 입력]`  
연구 책임자와 연락처: `[모집 전 입력]`  
기관 검토 정보: `[해당 시 모집 전 입력]`

이 문서는 실제 동의를 받은 기록이 아니다. 기관의 연구·윤리 검토 요구와 적용 법규를 확인한 뒤 확정본을 참가자에게 제공한다.

## 연구 목적

이 연구는 외부 AI Skill·MCP 구성요소를 검토할 때 보안 근거의 제시 방식이 승인·보류·거절 판단, 검토 시간, 확신도에 어떤 영향을 주는지 탐색합니다.

## 참여 내용

참가자는 연구용 가상 사례의 목적·정책·검토 자료를 읽고 승인, 보류, 거절 중 하나를 선택합니다. 판단 이유, 추가로 필요한 근거, 판단에 대한 확신도를 기록합니다. 연습 과업과 본 과업, 선택적인 사용성 질문이 포함될 수 있습니다.

예상 소요 시간: `[모집 전 입력]`  
보상과 지급 조건: `[없음 또는 모집 전 입력]`

## 예상되는 불편과 위험

- 여러 기술 자료를 읽고 판단하면서 피로하거나 답답함을 느낄 수 있습니다.
- 자유 의견에 실제 조직·프로젝트·비밀정보를 적으면 의도하지 않은 정보 노출 위험이 있습니다. 연구용 자료만 사용하고 실제 비밀을 입력하지 않아야 합니다.
- 연구자는 최소 정보만 수집하지만 작은 경험 집단에서는 응답 조합으로 재식별 위험이 완전히 없어지지 않을 수 있습니다.

참가자는 언제든 쉬거나 질문을 건너뛰거나 세션을 중단할 수 있습니다.

## 기대되는 이익

참여에 따른 직접적인 보안·금전 이익은 보장되지 않습니다. 연구 결과는 AI 워크플로 구성요소의 검토 지원 방식을 개선하는 데 참고될 수 있습니다.

## 수집 정보

수집 예정 정보는 다음과 같습니다.

- 무작위 participant ID와 최소한의 구간형 경험 정보.
- 연구 사례의 결정, 이유, 추가 근거 요청, 확신도.
- 연구 페이지에서 연 evidence 항목과 시작·제출 시간.
- timeout, 중도탈락, 기술 문제, 진행 담당자의 개입 여부.
- 선택적으로 제공한 비식별 자유 의견.

이름, 이메일, GitHub ID, IP 주소 원문, 실제 저장소·프롬프트·API 키, 전체 화면, 다른 탭, 키 입력, 클립보드는 연구 응답 데이터에 수집하지 않습니다. 연락처나 보상 정보가 필요하면 연구 응답과 분리하여 보관합니다.

음성·영상·화면 녹화: **기본적으로 수집하지 않음**. 녹화가 필요해지면 목적·항목·보관 기간을 설명한 별도 선택 동의를 받아야 합니다.

## 보관·접근·공개

응답 저장 위치와 암호화 방식: `[모집 전 입력]`  
응답 접근 가능 역할: `[모집 전 입력]`  
보관 기간과 파기 방법: `[모집 전 입력]`  
철회·삭제 요청 가능 기간: `[모집 전 입력]`

연락처·동의 기록과 연구 응답은 분리합니다. 연구 결과는 집계 형태로 보고하며, 자유 의견을 인용할 때 개인·조직을 식별할 수 있는 정보를 제거합니다. 비식별 자료의 공개 또는 재사용 범위는 아래 선택과 기관 요구에 따릅니다.

## 자발적 참여와 철회

참여는 자발적입니다. 참여하지 않거나 중간에 그만두어도 불이익이 없습니다. 철회 시 이미 제출한 응답의 처리 방법은 위의 철회 가능 기간과 익명화 시점을 따릅니다. 완전히 익명화되어 특정 응답을 찾을 수 없게 된 뒤에는 개별 삭제가 불가능할 수 있으며, 그 시점을 모집 전에 명시해야 합니다.
